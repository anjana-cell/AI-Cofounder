# AI Cofounder

### An Autonomous Multi-Agent Platform for Startup Idea Development

## Overview

AI Cofounder is an AI-powered multi-agent platform that transforms startup ideas into structured MVP development workflows.

It uses multiple specialized AI agents to analyze startup ideas, evaluate business feasibility, design system architecture, simulate MVP development, review security considerations, and generate GitHub workflow suggestions.

The platform provides a centralized dashboard where users can submit an idea and view structured outputs generated by the AI agents.

## Features

- **Multi-Agent Orchestration:** Coordinates multiple specialized AI agents to analyze startup ideas.
- **Business Validation:** Evaluates the feasibility and potential of startup ideas.
- **Architecture Generation:** Suggests suitable system architectures and technologies.
- **MVP Workflow Simulation:** Generates structured MVP development steps.
- **Security Review:** Identifies potential security considerations.
- **GitHub Workflow Simulation:** Provides GitHub-related development workflow suggestions.
- **Interactive Dashboard:** Displays agent outputs through a React-based interface.
- **Live and Mock Modes:** Supports live AI-powered execution and mock execution for testing.

## Project Workflow

1. The user submits a startup idea through the frontend dashboard.
2. The frontend sends the idea to the FastAPI backend.
3. The backend orchestrator coordinates the specialized AI agents.
4. Each agent performs its assigned analysis.
5. The orchestrator collects the outputs and generates a structured JSON response.
6. The frontend displays the results in the dashboard.

## Installation and Setup

### Prerequisites

Make sure the following tools are installed:

- Python
- Node.js and npm
- Git

### 1. Clone the Repository

```bash
git clone <repository-url>
cd <project-folder>
```

### 2. Backend Setup

Navigate to the backend directory:

```bash
cd backend
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI server:

```bash
py -m uvicorn main:app --reload
```

The backend will run at:

```text
http://localhost:8000
```

API documentation:

```text
http://localhost:8000/docs
```

### 3. Frontend Setup

Open a new terminal and navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The frontend will be available at:

```text
http://localhost:3000
```

## API Reference

### Generate Startup Analysis

**Endpoint:**

```http
POST /generate
```

**Request Body:**

```json
{
  "idea": "AI Finance Analyzer",
  "live_mode": false
}
```

The API processes the submitted startup idea through the multi-agent orchestration system and returns structured results.
